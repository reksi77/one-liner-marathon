A single deadpan one-liner for make.fun's One-Liner Marathon: a voicemail greeting recorded at twenty-two, still answering calls from a stranger who hasn't been disappointed yet. The program writes exactly that one line to `/output/entry.txt` — no randomness, no network, byte-identical on every run.

## Run it

```sh
node main.ts
```
